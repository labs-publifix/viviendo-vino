# Backlog del blog

Lista de temas para escribir, uno por semana. Claude Code toma de aquí el siguiente tema con estado **idea** o **listo** (ver `README.md`).

## Cómo se usa

- Agrega una fila por tema. El **número** es consecutivo y no se reutiliza.
- **Tipo**: `articulo` o `guia` (las guías llevan PDF descargable).
- **Categoría**: una de las del blog (`Aprende`, `Guías de maridaje`, `Del catálogo`) o una nueva si hace falta.
- **Estado**: `idea` → `redactando` → `listo` (escrito y revisado, sin publicar) → `publicado`.
- **Fecha objetivo**: AAAA-MM-DD en que debería publicarse.
- Al publicar, cambia el estado a `publicado` y anota el slug en el tema, por ejemplo: `Cómo leer una etiqueta (como-leer-la-etiqueta-de-un-vino)`.
