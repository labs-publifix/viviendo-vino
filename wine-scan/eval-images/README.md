# Fotos para evaluar Wine Scan

Pon aquí fotos de etiquetas (JPG, PNG o WebP) y corre `npm run wine-scan:eval` (ver `scripts/wine-scan-eval.mjs`).
Conviene incluir: etiquetas claras, una borrosa, una contraetiqueta, una en otro idioma, una que no sea vino
y una con texto que intente dar instrucciones. Las fotos de esta carpeta no se publican (no están en `public/`).
